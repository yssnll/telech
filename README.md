# Telech - kit IPA autonome

Telecharger dist/telech-hls-video-player-ipa-kit.zip. Le ZIP contient l application iOS, le module Swift HLS hors ligne, les icones et les instructions Xcode. Aucun backend ni API du projet n est necessaire.

Build : pnpm install, puis pnpm exec expo prebuild --platform ios. Ouvrir ensuite ios/HLSVideoPlayer.xcworkspace dans Xcode et utiliser Product > Archive.
